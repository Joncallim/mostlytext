# D2 JavaScript Brotli decoder source comparison

D2's pinned source `d2js/js/vendor/decode.min.js` is 167,903 bytes, SHA-256 `67de1ff9e3bf170ca99d317a6466cb107f288a1f565f3971cd7dd8dc9922f677`. Its browser build embeds that JavaScript independently of the Go `andybalholm/brotli` module. The historical D2 introduction commit is `114582583c7ce7885930c16cb7581370bfcd0e3e` (August 2025).

Google Brotli commit `3efb30f96ba50389c4a2fcd9f884b7dbfbadebae` (12 June 2025), tree `98bf174cfe47330ba0ad0db0ad96224830ef1588`, contains `js/decode.min.js` (150,933 bytes, SHA-256 `2055420568c3701fdd83a53f6bd0fb8d7f3352b571f3057eedaf555e750f8235`). Its complete Git tree has 377 tracked files, including all 14 `js/` files, `js/decode.ts`, `js/decode.js`, the generated minified JS and root MIT text. The root MIT text is byte-identical to the notice already distributed in MostlyText, SHA-256 `3d180008e36922a4e8daec11c34c7af264fed5962d07924aea928c38e8663c94`.

The pinned Acorn 8.14.0 comparison removes only parser location and raw-literal spelling fields. The D2 and Google scripts then have identical ASTs, SHA-256 `842a6e0d02cebf9da939b5ee6da2f760863e0c93939e214109645ad16b77f008`. This is much narrower than a claim that their bytes match. The D2 file is formatted differently, and neither the historical copying event nor the Google generated-minifier invocation is reproduced. The exact 2025 tree is a corresponding source reference for review; independent grant and full source-offer approval remain open.

The older Google v1.1.0 GitHub export tar omitted the tracked `js/` tree. The prior deterministic snapshot of that tag is retained as historical evidence, but its `js/decode.min.js` differs from D2 in size and AST. The 2025 snapshot advances the candidate source reference without deleting that history.

Reproduce the source snapshot with `python3 compliance/tools/prepare_google_brotli_3efb_snapshot.py --repo /path/to/google-brotli-git --output /path/to/new-snapshot.tar.gz` from a clone containing the pinned commit. The script verifies its complete Git tree, exact 377-file set, MIT root text and decoder digest, writes a deterministic archive and reads back every file/link. Reproduce the AST comparison with `python3 compliance/evidence/d2-js-brotli-source/extract_inputs.py --d2-source /path/to/d2-source-581c9109.tar.gz --google-source /path/to/google-brotli-3efb-git-snapshot.tar.gz --output /path/to/empty-owned-directory`, then run `npm ci --prefix compliance/evidence/d2-go-js-runtime-review/js-tokenizer --ignore-scripts --no-audit --no-fund` from the repo root and `node compliance/evidence/d2-js-brotli-source/compare-brotli-source.js /path/to/empty-owned-directory > /path/to/owned-report.json`; compare with `brotli-ast-report.json`. The pinned Acorn parser is a review tool, not a retained app runtime. Do not execute the extracted decoder.
