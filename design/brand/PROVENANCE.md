# MostlyText brand provenance and licensing

**Owner summary.** This records where every brand element came from, under
what licence, and which files are canonical. The mark is original vector
geometry written in this repository. The wordmark typeface is Inter Tight,
under the SIL Open Font License 1.1. No font files are stored in the
repository.

## Mark (Slant)

- **Origin:** original geometry, authored as code in this repository and
  iterated through rounds gen2 → gen3 → Slant. No stock artwork, traced
  images or third-party logo files were used. The first exploration board
  (five T concepts) was supplied by the owner as an image. Its origin isn't
  recorded here and it is not in the repository. Slant does not derive
  geometry from it.
- **Sources:**
  - `design/brand/slant/marks.mjs` (variant `s10`: 10° lean, wedge cut, stems
    17, diagonals 15; D-011 construction at the D-027 lean);
  - `design/brand/slant/validation/small.mjs` (the 32 px master and 16 px
    microglyphs, derived from the master at 10°; D-014, D-020, D-027, D-029).

| Designer | Rasmus Andersson |
| Copyright | "Copyright 2022 The Inter Project Authors (https://github.com/rsms/inter-tight)" |

| Upstream source | https://github.com/rsms/inter-gf-tight at commit `c194f94c60b569b47876811321f5ef1f0c2614a2`, file `fonts/variable/InterTight-Italic[wght].ttf` (per google/fonts `ofl/intertight/METADATA.pb`) |
| Google Fonts listing | https://fonts.google.com/specimen/Inter+Tight (added 2022-07-22) |
| Served version used by the boards | Google Fonts `intertight/v9`, via `https://fonts.googleapis.com/css2?family=Inter+Tight:ital,wght@0,700;1,700` (checked 2026-09-25) |
| Licence text | https://raw.githubusercontent.com/google/fonts/main/ofl/intertight/OFL.txt |

**Basis for use.** OFL 1.1 lets the font be used to create artwork, including
logos. Outlined wordmark artwork made with the font is not "Font Software" under
the licence, and the licence doesn't require the artwork to carry the OFL. If
the font files themselves are ever redistributed (for example bundled into the
website), the OFL text and copyright notice must go with them. **No font
binaries are committed here.** The Figma session should use Google Fonts'
Inter Tight, or an OFL copy downloaded from the upstream source above, and
record the version it used.

**Not used:** Apple's SF Pro. Its licence limits it to mock-ups of Apple
platform UI and doesn't allow logo use (D-012).

## Canonical assets

Only these files are authoritative. Everything else in `design/brand/` is
exploration history or review boards.

| File | Use | Generated by |
|---|---|---|
| `design/brand/slant/validation/slant-master.svg` | Mark above 40 px, and all general artwork | `design/brand/slant/validation/build.mjs` from `slant/marks.mjs` (`s10`) |
| `design/brand/slant/validation/slant-32.svg` | Mark at 18–40 px | same build, from `validation/small.mjs` (`v32`) |
| `design/brand/slant/validation/slant-16.svg` | **Microglyph**, ≤17 px only, never enlarged (D-020) | same build (`P16`) |
| `design/brand/slant/validation/slant-icon-16-inner.svg` | **Microglyph** inside the 16 px app icon only (D-020) | same build (`PI16`) |

**Not canonical:**
- `design/brand/gen2/`, `design/brand/gen3/`: rejected rounds.
- `design/brand/slant/*.svg` (`s8`, `s10`, `s12`, `s15`, `p12`): tuning variants. `s10.svg` is geometrically the production mark and `s12.svg` the superseded 12° one (D-027), but the validation export is the canonical file.
- All `board.html`, `lockup.html` and `validation.html` pages.
- The read-test decoys.

**Colour:** the icon's two-tone values (light: M `#14171D`, T `#2F5FE6`;
dark: M `#F3F5F9`, T `#7EA4FF`) are working values used on the boards. They
are not frozen, and the macOS icon build may change them.

## Rebuilding

All generated files rebuild deterministically from their checked-in sources.
Verified 2026-09-25, and again on 2026-09-27 after the 10° cascade: rebuilding
every board and asset produced no changes in the working tree. The production
outlines (`design/brand/slant/production/`, `npm ci && npm run build`) need
the Inter Tight Bold Italic TTF placed next to the scripts, as that folder's
README describes; it is git-ignored and not committed.

```sh
cd design/brand/gen2 && node build.mjs
cd design/brand/gen3 && node build.mjs
cd design/brand/slant && node build.mjs && node lockup.mjs
cd design/brand/slant/validation && node build.mjs     # canonical SVGs + validation board
cd design/validation/read-test && node build.mjs       # read-test stimuli (needs Playwright + Chromium)
```

## Application icon integration

The shipped source `MacDown2/MacDown2/AppIcon.icon` is a byte-identical copy of
`design/evidence/2026-09-26/icon-art/MostlyText-lean10.icon`, the D-028 accepted
Icon Composer document: original Slant geometry on the existing automatic blue
gradient. It contains only `icon.json` and `Assets/lean-10-1024.png`; no font or
third-party artwork is bundled. Keep the document adjacent to Assets.xcassets,
not nested within it, and keep a single AppIcon source. Xcode builds the
appearance/tint renditions. See the evidence README for the validated integration
path. The old placeholder generator is historical tooling and must not regenerate
a competing AppIcon.appiconset in current production source.
