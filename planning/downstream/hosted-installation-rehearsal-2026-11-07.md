# Rehearse normal installation migration on a disposable Mac

## Owner summary

Prove that a normal Release app adopts a generated development profile before
opening documents and preserves its unsaved recovery across normal Quit and
relaunch. The old profile remains unchanged. This fills an engineering gap in
#3/#5/#17; it does not certify an installed, quarantined or signed release.
The generated profile exists only on an admitted disposable hosted Mac.

merge aff49a5e and its evidence-only descendant. PR124's exact candidate passes
complete CI, original tab/conflict cases, public CLI/focus/status and required

## Journeys and invariant

First slice: prepare a source-bound fixture, held before profile mutation.
A later fixed controller mode is activated only after current licence/public
orchestration results are preserved and its actual main intake is reconciled.

After exact host admission and a genuine private input positive, assert all
current/development/original-MacDown domains and support roots absent. Seed only
this fictional profile: a generated external text document; a valid managed
snippets file with distinct unsaved recovered text; a canonical custom theme;
a data-only executable-command sentinel that must never execute; completed
fictional development onboarding. Record every input byte, mode and identity,
source preferences and exact session UUIDs/epochs/baseline digests. Do not pass
- UITesting, session overrides or environment injections to the normal app.

Launch normally through the identity-bound external host. Require the actual
restored managed document's unsaved text, both expected document identities and
absence of migration failure/optional offer. Inspect actual migrated defaults,
working state, preserved copy and managed session/recovery path relocation.
Normal Quit must preserve source files/domains and current unsaved recovery.
Relaunch the same exact app, require the same two tabs and unsaved text with no
duplicates or stale preference reapplication, then normal identity-bound Quit.
No unrelated process, source profile or unknown preference is reset/deleted.

Second independent case, after valid adoption is understood: a future-version
session must yield real blocked startup, no ordinary writer/listener, normal
Quit and unchanged old/current records. Its first outcome stays separate.

## Ownership, data flow and interfaces

The private fixture tool creates canonical profile bytes on the exact admitted
runner account/home only. It never calls migration/startup directly; the ordinary
app must do that work. Bind fixture source, generated manifest/package/lock,
compiled fixture and normal app/helper/driver paths/hashes. Controller admission
must precede receipts, domains, files and ancestry commands. Refuse optimized
Python and unresolved anchors. The fixture executable independently validates
real host identity and a verified positive-control receipt before any profile
write. No caller-supplied home, domain, support root or arbitrary path is accepted.

The driver reads only bound fictional oracles and real public window state.
Keep genuine typing/clipboard/menu controls and original 120-second case,
600-second owned command and 40-minute job limits. Each phase has a separate
actual result/owned outcome; zero cases, skipped/expected failures, cancellation,
timeout, wrong identities, source drift or cleanup uncertainty fail closed.
Preserve the first raw result before classifying any selector or product failure.

## Slices and stop conditions

1. Canonical fixture source plus held/host/positive-before-mutation controls.
   Source verification does not establish that it compiles or executes natively.
2. Reconcile current licence/public controller and actual main; write the fixed
   migration mode, complete source/generated/resource/fixture binding and private
   UI journey. Review any integration assumption before activation.
3. One actual fresh-Mac valid-adoption run; independently verify all inputs,
   genuine positive/UI results, actual domains/files/epochs/identities and normal
   Quit/relaunch. Preserve failure before a material correction; no unchanged retry.
4. Independent blocked-future case, then bounded issue updates and current full
   checks/review/expected-head merge. Audit whole issue set after each metadata
   change; no broad criterion may be inferred from these fictional profiles.

Stop when a source encoder/admission assumption fails, public selectors differ,
profile identity changes unexpectedly, original bytes are touched or native
cleanup cannot be established. Amend architecture before changing policy or
ownership. Final installed-state, TCC/security-scoped owner access, original-
MacDown real data, Sparkle chain, independent rights, VoiceOver and exact signed
artifact acceptance remain explicit external/final gates.
