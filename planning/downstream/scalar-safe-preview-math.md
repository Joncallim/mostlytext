# Scalar-safe native Preview math transport

## Owner summary and baseline

Equations must keep their own source identity and native inline placement without
changing nearby Unicode, reference links or Markdown formatting. This bounded
transport adapts already analyzed occurrences; it does not recognize dollar math,
validate TeX or introduce another renderer. It is the next unit of the binding
shared-math-activation contract. Main remains abc3a5c851351d28b790edac7d7b1269c8870f87;
PR90's reference repair is in hosted qualification at 0db3b39c. This branch contains
that exact source plus the separately documented placement/font probes. Native
execution is hosted only. Owner-account and final-app acceptance stay held.

## Ownership and interface

PreviewMathInput is Foundation-only and immutable. It owns the original visible
block, a complete rewritten parser input, a random input identity, a source-absent
ASCII marker family and a dictionary of generated markers. Replacements carry an
opaque occurrence UUID, original block-local UTF-16 range and exact expected source.
Additional ordinary source edits carry the same proof fields and replacement text;
these are the app's translation of the shared MarkdownReferenceRepair result.
No document or MarkdownEngine state is fabricated inside Preview.

PreviewMathMarkupParser uses the existing AttributedStringMarkdownParser with source
positions enabled and NO syntax extensions. The app supplies a dictionary from the
same occurrence UUIDs to its already validated typed AnyAttachment values. A missing
attachment restores that occurrence's original authored text, with inherited link
and style attributes. A new source attribute stores only the occurrence UUID; source
authority stays with the app's live snapshot/navigation guards. Preview has no new
MathRendering dependency. App publication and simultaneous Export activation follow
in the next unit, after this transport is qualified.

## Input validation and bounds

The entire expanded input, including reference-definition prefix, markers and ordinary
repairs, is limited to 64 KiB UTF-8. One shared Foundation constant also supplies the
existing PreviewBlock cap. Check the projected byte total before materializing.
At most 1,024 total edits and 512 replacements are admitted. Require unique occurrence
UUIDs, nonempty in-bounds nonoverlapping ranges, exact UTF-8 expected source and
boundaries that split neither a UTF-16 surrogate pair nor CRLF. Empty edit lists are
valid, but oversized prefix/input and mismatched source are rejected. A nonempty
prefix must finish with a blank line; callers retain responsibility for supplying
actual parser-derived reference definitions, never synthesized URLs or titles.

The marker family is MTEQ plus a 32-character uppercase hexadecimal nonce plus Z;
markers append an ASCII decimal ordinal and Q. The family must be absent by literal
UTF-16 comparison from original source, prefix and ordinary replacement strings.
The nonce is regenerated by the caller on a reported collision; tests may supply a
fixed nonce. Source edits are sorted and applied in one forward pass; generated
ranges include prefix and preceding repairs. Arithmetic is bounded by admitted
source/edit sizes. Cancellation is checked during admission and rewriting.

## Parsing, scalar restoration and failure

Build a scalar-offset mapping from the actual AttributedString unicodeScalars, not
Character indices or String.range searches. Find the literal marker family in that
scalar string, require an exact registered marker and exactly one occurrence of each
entry, and map its endpoints back through actual scalar indices. Every marker run
must be outside inline/block code and HTML, and its parser source position must
cover the actual generated UTF-16 range in this exact rewritten input. This rejects
entity-decoded forgeries as well as missing, duplicate or unknown markers. Preserve
inherited attributes and native presentation intents when inserting each single
FFFC attachment or authored literal fallback. Canonically equivalent strings are
not interchangeable source identities. No nonce may escape to visible output.

Any input/parser/provenance failure returns the whole original visible block as
plain attributed text, without a marker, partial derived publication or a diagnostic
storm. Transport failure is distinct from malformed TeX. The app later records its
localized structured state. No authored document mutation occurs.

## Verification and stop conditions

controls. Actual Preview target compilation remains non-executing. Hosted tests use

Native parser tests cover Prepend, combining marks, variation selectors, ZWNJ,

unknown/missing/duplicate/entity-forged markers; complete-input boundaries and

the separate placement/font regression tests remain unchanged. If parser source
positions cannot prove a valid occurrence, retain readable fallback and investigate
before production activation; do not remove the provenance gate or replace real
native execution with a stub.
