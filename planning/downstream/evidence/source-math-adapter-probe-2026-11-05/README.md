# Original-source math attachment feasibility — hosted proof pending

This slice adds no production math activation. It exposes a typed factory for
Textual's existing MathAttachment, preserving old nil-identity construction and
adding an optional occurrence UUID. The same SwiftUIMath pin, original MIT
licence, parser, body, baseline, size and block classification remain intact.
Only Textual's app pin changes relative to the prepared lexer predecessor;
23 other pins are verified unchanged. The source factory compiles locally.

A Foundation-only executable confirms actual Markdown source positions,
collapsed-reference loss and the explicit-original-key correction. It also
shows markers can be synthesized across attributed runs or HTML entity decoding.
That spike is not the native Textual/attachment probe. Exact source and outputs
are retained. It executes no AppKit/SwiftUI/WebKit/product code.

Six exact PreviewTests source/helper files prepare the real probe: pre-admitted
fixture spans, checked original/rewrite coordinates, explicit reference keys,
unique namespace and occurrence IDs, real Textual parsing with .math disabled,
source-position/preformatted provenance checks, typed attachments and readable
original-source fallback. Count/input/overlap bounds protect the experiment.
The helpers remain test-only until this feasibility gate passes; they are not a
production admission parser and do not establish the shared delimiter grammar.

Fourteen positive fixtures cover escapes, TeX Markdown punctuation, emphasis,
inline/full/collapsed/shortcut/shared references, original definition/title bytes,
literal code, currency admission, duplicate equations, Unicode/CRLF and multiline
percent comments. They require exact original span/TeX/identity/target attributes
and actual attachment metrics. Additional controls require old-factory equality,
distinct occurrences, original collapsed-key loss, paragraph reading order and
real native text construction/layout. Missing, duplicated, misplaced, forged,
preformatted, overlapping, surrogate-splitting and colliding input must fall back
to readable authored source without generated-marker leakage. No sleeps.
