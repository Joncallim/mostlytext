# Inter font files

Inter 4.001 (`git-66647c0bb`), static Regular (400) and SemiBold (600), from the Inter project (https://github.com/rsms/inter). Licensed under the SIL Open Font License 1.1; see `Inter-OFL.txt`. No Reserved Font Name is declared.

The `.ttf` files are the source assets. The `.woff2` files are lossless conversions of them, made with fontTools 4.60.1 and brotli 1.1.0 (`TTFont(src); flavor = "woff2"; save(dst)`), without subsetting. Glyph order (2,871 glyphs), character map (2,849 code points), table set and outlines match the TTFs. The site serves WOFF2 first and falls back to the TTFs.
